# Prompt Eksekusi Awal — Sistem Informasi Buket Bunga

Salin prompt ini ke agen coding setelah dokumen SOT disetujui.

---

Kamu bertindak sebagai system analyst, frontend developer React, UI/UX engineer, dan prompt engineer. Bangun **Sistem Informasi Buket Bunga berbasis web** menggunakan **React + Vite**, dengan mengikuti dokumen `PRD.md`, `UI-GUIDELINE.md`, `IMPLEMENTATION_PLAN.md`, dan kontrak `AGENTS.md`.

## Aturan wajib
1. Baca semua dokumen tersebut terlebih dahulu.
2. Jangan mengerjakan fitur di luar SOT.
3. Jangan mulai coding jika SOT belum mendapat persetujuan eksplisit dari pemilik proyek.
4. Eksekusi **Phase 1 saja** pada awal pengerjaan. Jangan lanjut ke Phase 2 otomatis.
5. Sebelum mengubah proyek yang sudah ada, periksa struktur file dan jelaskan rencana perubahan yang berisiko.
6. Gunakan dependency seminimal mungkin. Minta persetujuan sebelum menambahkan dependency besar.
7. Jika backend belum tersedia, gunakan mock data yang jelas ditandai sebagai demo. Jangan mengklaim autentikasi atau data mock aman untuk produksi.
8. Gunakan Bahasa Indonesia dan gaya visual modern futuristic SaaS dengan brand pink, kuning, dan putih.
9. Jangan mengarang nama toko, nomor WhatsApp, atau informasi bisnis. Gunakan placeholder yang mudah diganti.
10. Jangan menganggap tombol selesai jika belum memiliki aksi yang sesuai.

## Target Phase 1
- Siapkan fondasi React + Vite sesuai struktur pada `IMPLEMENTATION_PLAN.md`.
- Buat token warna dan style global dasar dari `UI-GUIDELINE.md`.
- Siapkan routing dan struktur direktori minimal yang diperlukan, tanpa mengimplementasikan seluruh halaman.
- Pisahkan mock data dari komponen UI jika diperlukan pada fondasi.
- Buat README dengan prasyarat dan cara menjalankan proyek.
- Pastikan proyek dapat dijalankan dengan perintah yang sesuai dan jalankan build/lint yang tersedia.

## Format laporan setelah Phase 1
- Ringkasan pekerjaan.
- File yang dibuat/diubah.
- Perintah pemeriksaan yang dijalankan dan hasil aktual.
- Hal yang belum dikerjakan dan alasannya.
- Risiko/asumsi yang perlu keputusan pemilik proyek.
- Akhiri dengan pertanyaan: **“Apakah Anda menyetujui hasil Phase 1 dan mengizinkan saya melanjutkan ke Phase 2?”**

Berhenti setelah laporan. Jangan memulai Phase 2 sampai pemilik proyek memberikan persetujuan eksplisit.
